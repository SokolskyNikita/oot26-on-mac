# Known issues

The faults of one build: the emulator this repository pins and rebuilds. That build is Lichii `d2ca32974d` with the
7 patches in `patches/lichii/`, and MoltenVK `5189f8de86ec` with the 11 patches in `patches/moltenvk/`. SPIRV-Cross
is pinned at `98cbb7c0`. Guest code runs on the dynarmic JIT with one 512 MiB code cache shared by the six guest
cores. The build was installed as `/Applications/lichii.app` on 2026-11-19, and the pins are in
[versions.lock](versions.lock). This list covers only that build, run with the settings and switches in
[config/](config/README.md). Faults of stock Lichii, of experiments that were not adopted, of the unfinished
Hypervisor work and of the builds before the fixes are listed only under "Not this build", with pointers to where
they are tracked. Ideas and experiments are in [TRACKER.md](TRACKER.md). Last review: 2026-11-19.

The "How it is known" column has one of three values. "Seen in the game" means it was observed on a running or
installed build: on screen, in a run's pictures, in its log, or with a tool run on the installed app. "Read from the
code" means it was found by reading the source and has never been observed. "Found offline" means a test outside the
game showed it: a standalone shader or Metal test, a GPU-trace replay, or a shader preparation run. Run folders named
`ab-<date>-<time>` are local run data and are not tracked.

## Keeping this file

- A fault found in the pinned build gets a row in the section that fits the day it is found, with the next free
  KI number. Numbers are never reused.
- When a fault is fixed, its row moves to "Fixed" below, with the patch or commit that fixed it and the date.
- When the pins in [versions.lock](versions.lock) change, every row is checked against the new source and the review
  date above is updated.
- Ideas, experiments and measurements go to [TRACKER.md](TRACKER.md), not here.
